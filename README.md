# LemmaCraft — Math Proof Adventure

LemmaCraft is a visual mathematical proof engine with a custom parser and internal model that enables users to derive Peano-arithmetic results from a minimal set of axioms. Designed as a four-chapter learning progression, it teaches users both the software and foundational proof concepts across addition, multiplication, and exponentiation. Influenced by the Natural Number Game in Lean, LemmaCraft replaces textual proof commands with an intuitive drag-and-drop interface, lowering the barrier to entry while retaining core logical structure. The engine is implemented without external proof assistants to maintain control and simplicity, featuring a modular architecture that distinguishes between UI, level logic, and mathematical objects. Despite limitations in semantic parsing and variable handling, LemmaCraft demonstrates that graphical proof construction is feasible and approachable for learners unfamiliar with formal proof languages.
